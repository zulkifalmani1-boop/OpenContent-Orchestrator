# OpenContent Orchestrator 🎬🤖

A lightweight, open-source Python CLI designed to automate the heavy lifting of content creation. It acts as a pipeline orchestrator to convert raw text scripts into synthesized audio using various TTS APIs (Deepgram, Google Cloud TTS, Edge TTS) and prepares asset folders for video editors.

## 🚀 Why this exists?
Many creators struggle with manually generating voiceovers, managing API keys, and organizing assets for large documentary or true-crime videos. This tool bridges the gap by providing a simple command-line interface to batch-process scripts.
